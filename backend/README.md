# VinaxMart Backend

Java 17 + Spring Boot + MySQL + Spring Security + JWT.

## Run
1. Install Java 17, Maven and MySQL.
2. Update `src/main/resources/application.properties` with your MySQL username/password.
3. Run `mvn spring-boot:run`.
4. API: http://localhost:8080

Admin seed: `admin@vinaxmart.com` / `Admin@123` (change this before deployment).
